配置の意図

  • 注文番号を見出しに置く。問い合わせのときに読み上げられる値であるため
  • 状態・納品予定日・合計を明細より上に、ラベルと値の対で 3 行積む。 「いつ届くか」「いくらか」がこの画面を開く動機であり、何を頼んだかの確認はその後に来る。 合計を明細表の外に出すことで、明細の小計との読み違えを避ける
  • 明細に「注文の内容」と見出しを付け、上の 3 行と切り分ける
  • 書名から書籍の詳細（SCR-BOOK）へ戻れるようにする。 同じ本をもう一度買うか、内容を確かめ直す動線であるため
  • 「戻る」を表の下に置く。この画面には状態を変える操作が無く、 一覧へ帰ること以外にすることがない
