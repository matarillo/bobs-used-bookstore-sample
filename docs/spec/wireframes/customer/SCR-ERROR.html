配置の意図

  • 見出しと 1 文だけを最上段に置く。利用者が受け取るべきはこの 2 行だけであり、 以降は読まなくてよいものとして下に置く
  • 要求 ID を 2 行の直下に置く。問い合わせのときに読み上げられる値であり、 説明文より先に目に入る位置に要るため
  • 「開発モード」以下は開発者に向けた面である。利用者向けの 2 行と 見出しで切り分け、混ざらないようにする
  • やり直しの導線を版面に持たない。入力内容は失われており、戻る先が定まらない （同 §5）。共通フレームの導線だけが出口である
