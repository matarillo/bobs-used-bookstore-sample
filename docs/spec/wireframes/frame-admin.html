配置の意図

  • 仕事の対象（注文・買取・在庫）を横に並べ、ダッシュボードを先頭に置く。 ダッシュボードが仕事を配る画面であり、そこから各一覧へ散る導線が主であるため
  • 参照データは仕事の対象ではなく設定であるため、右端に離す
  • 通知バナーの居場所は店頭と同じ位置に固定する。見た目は別だが役割は同じ （横断的な約束事 §1）
  • 利用者名は導線を兼ねない。店頭では自分の住所へ行けるが、 管理では名前を出すだけである。代わりに「店頭へ」を隣に置く
  • 店章の行き先は注文一覧である（ダッシュボードではない）。 管理画面を開いたときの既定画面と同じ場所へ戻す
  • フッタは著作権表示 1 行だけで、案内の列を持たない。 仕事の導線はヘッダに揃っており、面の下端に重ねる必要がないため
