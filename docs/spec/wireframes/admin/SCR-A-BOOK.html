配置の意図

  • 表紙画像を左に固定し、右に項目名と値の表を積む。 店頭側の書籍詳細（SCR-BOOK）と同じ 2 段組を使う。 スタッフが「顧客にはどう見えているか」を思い浮かべられるようにする
  • ただし表の中身は店頭側と順序が違う。ジャンルと売価を上位に上げ、 出版社・ISBN・書籍種別を後ろに送る。値付けを見直す目で開く画面であるため
  • 仕入原価と粗利見込を表の末尾に、供給元オファーとひと続きで置く。 この 3 行は揃って現れるか揃って消えるかのどちらかであり、 「この 1 冊で儲かっているか」を読む一組である
  • 在庫数を置く場所を版面に持たない（一覧には出る）
  • 更新への導線を持たない。「戻る」だけを最下段に置く
