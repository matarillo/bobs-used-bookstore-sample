配置の意図

  • 店頭のエラー画面（SCR-ERROR）と作りが違う。 こちらは中央寄せの短い面で、開発者向けの説明を持たない。 使うのが店の中の人だけであり、詳しい情報は記録側で追うためである
  • エラーコードを見出しと本文の間に置く。問い合わせのときに読み上げられる値であり、 3 行のうち唯一その場に固有の情報である
  • 出口を 2 つ、中央に並べて置く。店頭側は出口を持たないが、 こちらは仕事の途中で落ちた人を戻す必要がある
  • 「トップへ」の行き先は店頭のトップであり、管理画面ではない。 版面はその区別を示さないが、押した先が管理の外へ出ることは意図した振る舞いではない （Q-07 の一部として扱う）
