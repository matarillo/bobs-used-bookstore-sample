配置の意図

  • 配送先と注文の情報を左右に並べた 2 枚の札にする。荷札を書く作業と 金額を確かめる作業が別であり、上下に積むと視線が往復するため
  • 配送先は宛名書きの形（氏名・住所行・市区町村と州と郵便番号・国）で積む。 そのまま書き写せる並びにする
  • 状態を右の札の 1 行目に置き、次に進める操作をその値の隣に置く。 この画面で唯一の状態を変える操作であり、今どこにいるかと並べて見せる
  • 小計・税・合計を 3 段に分けて出す。顧客側の注文詳細は合計しか出さないが、 ここでは内訳を見る必要がある
  • 品物の表は分類 4 軸まで並べる。顧客側より列が多いのは、 棚から実物を探すための情報が要るからである
  • 「戻る」を最下段に置く。一覧へ帰る以外にこの画面から進む先は無い
