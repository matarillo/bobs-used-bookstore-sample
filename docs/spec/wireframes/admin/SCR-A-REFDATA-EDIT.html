配置の意図

  • 項目が 2 つしかないため、面の左半分に寄せて置く。 全幅に伸ばすと入力欄が長くなりすぎ、短い名称を入れる欄に見えなくなる
  • 種別を先、名称を後に置く。種別が名称の意味を決めるため、 一覧（SCR-A-REFDATA）の列の並びと揃える
  • 保存できなかったときのメッセージだけは見出しより上に出る。 項目ごとの検証を画面が行っていないため、欄の直下に出す場所が無い
  • 「保存」と「戻る」を項目のすぐ下に置く。2 項目しかない面であり、 最下段まで離すと空きが間延びする

状態による差分

状態版面の変化
登録種別を選べる。名称は空
書籍編集の「追加」から来た登録その軸の種別が初期選択された状態で描かれる
改名種別が書き換えられなくなる（値は見える）。名称に既存の値が入る

名称の検証を画面側で行っていないため、空のまま保存するとエラー画面へ落ちる （Q-25）。
