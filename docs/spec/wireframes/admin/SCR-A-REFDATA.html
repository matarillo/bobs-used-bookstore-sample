配置の意図

  • 在庫一覧（SCR-A-BOOKS）と同じ骨格にする。見出しと右上の作成、 絞り込みの枠、上下のページ送り。管理側の一覧はどれも同じ形で読めるようにする
  • 種別を左端、名称をその右に置く。種別が名称の意味を決めるため （同じ「A社」でも出版社かジャンルかで別物である）、種別を先に読ませる
  • 名称の列を最も広く取る。ここだけが改名の対象であり、 表記のゆれを見比べる場所であるため
  • 0 件の文言を表の中に置く。枠の外に出さないのは、 一覧の内側が空であることを枠で示すためである
  • 操作は「更新」だけを右端に置く。削除も廃止も無いため、列は 1 つで足りる
