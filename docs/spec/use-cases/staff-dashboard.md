## UC-STAFF-01 — ダッシュボードで状況を把握する

| 項目 | 内容 |
| --- | --- |
| アクター | 店舗スタッフ |
| 画面 | `SCR-A-DASH` |
| ドメイン対応 | [OP-STAFF-16](../../design/domain/operations.md) / [13-read-models-and-statistics.md](../../design/domain/read-models.md) |
| 目的 | 今日の仕事の量と、事業が成り立っているかを一目で見る |

**【Boundary：画面】**

4 つの区画に分かれる。**多くの数字は、その数字に一致する一覧へのリンクを伴う**
（数えるだけでなく、仕事を配る画面である）。

### 区画 1: 注文

| 表示 | リンク先 |
| --- | --- |
| 受付待ちの注文が N 件 | `SCR-A-ORDERS`（状態＝受付待ちで絞る） |
| 納期超過の注文が N 件 | `SCR-A-ORDERS`（納期超過で絞る） |
| 今月の注文が N 件 | `SCR-A-ORDERS`（注文日 From ＝当月 1 日で絞る） |
| 累計の注文が N 件 | `SCR-A-ORDERS`（絞り込みなし） |

### 区画 2: 売上

| 表示 | リンク |
| --- | --- |
| 今月の売上 | なし |
| 累計の売上 | なし |
| 今月の粗利 ＋ **注記「〈金額〉の原価既知売上に対して。手入力した本には原価の記録がない」** | なし |

### 区画 3: 買取

| 表示 | リンク先 |
| --- | --- |
| 承認待ちの申込が N 件 | `SCR-A-OFFERS`（状態＝承認待ちで絞る） |
| 今月の申込が N 件 | `SCR-A-OFFERS`（**申込日の絞り込みは効かない** — 下記異常系） |
| 累計の申込が N 件 | `SCR-A-OFFERS`（絞り込みなし） |
| **承認待ちをすべて受け入れた場合に支払う額** | `SCR-A-OFFERS`（状態＝承認待ちで絞る） |
| 今月の買取支出 | なし |
| 累計の買取支出 | なし |

### 区画 4: 在庫

| 表示 | リンク先 |
| --- | --- |
| 在庫切れの書籍が N 冊 | `SCR-A-BOOKS`（在庫切れで絞る） |
| 在庫僅少の書籍が N 冊 | `SCR-A-BOOKS`（在庫僅少で絞る） |
| 在庫の総冊数 N 冊 | `SCR-A-BOOKS`（絞り込みなし） |

**【Controller：手順】**

1. 注文統計・買取統計・在庫統計を、それぞれ問い合わせる。
2. `SCR-A-DASH` に渡して描画する。

**【Entity：ルール】**

指標の定義はすべて [13-read-models-and-statistics.md](../../design/domain/read-models.md) にある。
業務担当者と読み合わせるうえで、特に取り違えやすいのは次の 4 点である。

| 論点 | ルール |
| --- | --- |
| **売上は税抜** | [RULE-SALES-02](../rules.md)。税は店の収入ではなく、他者のために預かるもの |
| **取消済以外はすべて売上** | [RULE-SALES-01](../rules.md)。出荷前でも受付前でも、注文が確定した時点で取引は成立している |
| **粗利は原価が分かる分だけ** | [RULE-SALES-03 / 04](../rules.md)。手入力した書籍は**粗利の計算から除外される**（0 として数えるのではない） |
| **買取支出は支払日で数える** | [RULE-PERIOD-05](../rules.md)。先月申し込まれ今月支払ったものは、**今月の支出**である |

> **粗利率を出すときの分母に注意する。**
> 「今月の粗利 ÷ 今月の売上」は**過小評価になる**。
> 正しい分母は画面が注記に出している「原価既知売上」である
> （[docs 13 §3.1](../../design/domain/read-models.md)）。

> **「今月の買取支出 − 今月の売上」は損益ではない。**
> 買取支出は払った月に、売上は売れた月に立つ。同じ 1 冊の出と入りは別の月に現れる
> （[docs 13 §5](../../design/domain/read-models.md)）。

**そのほかの前提**

- [RULE-PERIOD-02](../rules.md): 「今月」は**当月 1 日の 0 時**から始まる（問い合わせた時刻の時分秒は使わない）
- 「今月の注文数」「今月の申込数」の**基準日はドメイン未定義**。記録の作成日時に依拠している（[ISSUE-11](../../design/issues.md), [Q-29](../../product/open-questions.md)）
- 各指標の**集計式そのものはドメインに規定がない**。意味だけが定められている（[docs 13 §7](../../design/domain/read-models.md)）

**【異常系】**

| 起きること | 画面の振る舞い |
| --- | --- |
| 統計が取得できない | **すべて 0 として表示される。** 「取得できなかった」とは言わない（[Q-29](../../product/open-questions.md)） |
| 「在庫僅少 N 冊」をクリックした | **一覧の件数が N と一致しない。** 指標は在庫切れを**含まない**が、リンク先の絞り込みは在庫切れを**含む**（[Q-29](../../product/open-questions.md)） |
| 「今月の申込 N 件」をクリックした | **絞り込みが効かず、全件が出る。** 申込日で絞る条件が用意されていない（[Q-10](../../product/open-questions.md), [Q-29](../../product/open-questions.md)） |
| 数字が動く時刻 | 表示は問い合わせた瞬間の値。**自動では更新されない** |
