# 事業モデルと指標

## 1. 事業の循環

Bob's Used Bookstore は**中古書籍を顧客から買い取り、顧客に売る**店である。
事業は一つの単純な循環でできている。

```
顧客 ──買取オファー──> 店 ──棚入れ──> 在庫 ──注文──> 顧客
        （代金を支払う）              （売価をつける）
```

**安く買って高く売る。** したがってこのシステムが表現しなければならない最重要の事実は、
「**この 1 冊にいくら払い、いくらで売ったか**」である。

買取と販売は独立した二つの流れであり、**接点は棚入れただ一つ**である。
用語は [用語集](../glossary.md) を、構造は [ドメイン全体像](../design/domain/overview.md) を参照。

## 2. 測っている指標

店の状態は、[ダッシュボード](../spec/use-cases/staff-dashboard.md) の 4 区画で測られている。

| 区画 | 何を知るための数字か |
| --- | --- |
| 注文 | **今日の仕事の量**。受付待ち、納期超過、今月・累計の件数 |
| 売上 | **入ってきた金**。今月・累計の売上（税抜）と粗利 |
| 買取 | **出ていく金**。承認待ちの件数と、受け入れた場合に支払う額、今月・累計の支出 |
| 在庫 | **補充の判断**。在庫切れ、在庫僅少、総冊数 |

指標の定義は [読み取りモデル](../design/domain/read-models.md) にある。

### 2.1 粗利が測れない部分がある

粗利は**仕入原価が分かっている売上に限って**算出される。
手入力で登録した書籍は仕入原価を持たないため、売れても粗利に計上されない
（[RULE-SALES-03 / 04](../spec/rules.md)）。

したがって「粗利 ÷ 売上」は過小評価になる。正しい分母は原価既知売上である。

### 2.2 買取支出と売上は別の月に立つ

買取の支出は**支払った月**に、売上は**売れた月**に計上される。
同じ 1 冊の出と入りが同じ期間に現れることはない。
「今月の買取支出 − 今月の売上」は損益ではない。

## 3. 事業として決まっていないこと

| 事項 | 状態 |
| --- | --- |
| 買取価格の算定基準 | **なし**。顧客の申告に委ねられている（[Q-20](open-questions.md)） |
| 売価の算定基準 | **なし**。店の裁量（[Q-30](open-questions.md)） |
| 代金の受け渡し | **記録しない**。注文＝支払済ではない（[Q-28](open-questions.md)） |
| 送料・割引 | **概念が存在しない**（[Q-17](open-questions.md)） |

これらは事業の骨格に関わる未決事項である。[未決事項](open-questions.md) を参照。
