# ADR-0003 — 買取は顧客の希望額を承認／却下するだけとし、店側の査定額提示を見送る

| 項目 | 内容 |
| --- | --- |
| 対象 | STORY-21 / Q-20 / HYP-05 / EPIC-RESALE |
| 決めた人 | 店主（プロダクトオーナー） |
| 影響する文書 | [vision.md 非ゴール](../vision.md)、[story-map.md §5.1](../story-map.md)、[hypotheses.md HYP-05](../hypotheses.md)、[use-cases/customer-resale.md](../../spec/use-cases/customer-resale.md)、[use-cases/staff-offers.md](../../spec/use-cases/staff-offers.md) |

## 決めたこと

買取の流れを「顧客が本の情報と**希望額**を申告 → 店は**承認か却下**」の二択に絞る。
店から金額を提示し直す（カウンターオファー）段階を設けない。

## そう決めた理由

- 店頭の買取では店が査定するのが常識だが、**オンラインでは現物が手元にない**。
  現物を見ずに店が出す査定額は結局「仮の額」であり、受領後に揉める。
  それなら顧客に希望額を言わせ、店は受けるか断るかだけにする方が流れが単純である。
- 交渉（提示 → 顧客の同意 → 再提示…）を入れると、オファーの状態遷移が倍に増える。
  回るかどうか分からない流れに、その複雑さを先払いしない。
- これは**危険な仮説**である（HYP-05・リスク高）。だからこそ最小の形で早く市場に出し、
  承認率・却下率・支払到達率で検証する。

## 採らなかった案とその理由

| 案 | 採らなかった理由 |
| --- | --- |
| 店側査定（受領後に店が額を確定） | 顧客は額が分からないまま現物を送ることになり、送ってもらう心理的障壁が上がる |
| カウンターオファー（交渉） | 状態遷移と画面が倍増する。検証前の先行投資として過大 |
| 相場 API 等による自動査定 | 外部依存が増えるうえ、中古本の価値は状態で大きく振れる。この店の「1 冊ずつ検分する」という差別化（[vision.md](../vision.md)）とも合わない |

**再訪の条件**: 却下が常態化する、または希望額が相場から大きく外れて折り合わないとき
（[RISK-01](../risks.md)）。その場合は「承認済（発送待ち）」の前に「店の提示額に顧客が同意する」
段階を追加する方向で `AGG-OFFER` の状態遷移を見直す（[Q-20](../open-questions.md)）。
